# Pukmosina WordPress Theme

To jest prosty, dostępnościowy motyw WordPress dla strony typu lokalnej/instytucjonalnej:
- komunikaty
- statyczne strony
- rozkład jazdy
- harmonogram odbioru śmieci
- wysoki kontrast i prosta struktura

## Instalacja

1. Pobierz repozytorium jako ZIP.
2. Rozpakuj folder.
3. Wgraj folder `pukmosina` do katalogu `wp-content/themes/` na serwerze WordPress.
4. W panelu WordPress przejdź do `Wygląd > Motywy` i aktywuj motyw `Pukmosina`.
5. Po aktywacji sprawdź, czy zostały utworzone strony:
   - Rozkład jazdy
   - Harmonogram odbioru śmieci
   - Kontakt

## Uwagi

- To jest baza pod dostępność i prostą obsługę treści.
- Dla pełnego WCAG AAA warto wykonać finalne testy:
  - WAVE
  - axe DevTools
  - Lighthouse
  - test ręczny na klawiaturze
